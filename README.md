# Механік Полтава — Final Hardening Pack

Цей пакет підготовлений під поточний репозиторій `Sergiys23/mehanik-poltava`.

## Що змінено
- відео: до 500 МБ;
- R2 є основним сховищем відео;
- Google Drive — резервна копія, його помилка не повинна ламати R2 upload;
- ADMIN бачить робочі панелі;
- SUPERADMIN бачить усі панелі;
- публічні кнопки входу прибираються;
- Instagram AI/API/автоматичний імпорт не використовується;
- серверні перевірки ролей залишаються обов'язковими.

## Важливо
`public/admin.html`, `admin-role.js`, `admin-role.css` та `admin-entry-hide.js` можна замінити
відразу. Файл `worker-upload.patch.txt` містить точні зміни, які потрібно внести в
поточний `worker.js`. Не замінюйте worker цілком навмання, бо він містить робочу
логіку Google Drive, R2, D1, Telegram, таймерів і reset.
