Що виправлено:
- відео в картках тепер має стабільну рамку 16:9 і не розтягується;
- збережено пропорції відео через object-fit: contain;
- HTML5 відео не вантажиться наперед, щоб не тягнути весь файл при відкритті сторінки;
- у вкладці «Роботи» з'явився вибір джерела/плеєра;
- для Google Drive використовується HTML5;
- можна додати YouTube, YouTube No-Cookie, Instagram Reel або прямий MP4/WebM URL без завантаження файлу;
- Instagram та YouTube коректно відображаються на публічній сторінці.

ВАЖЛИВО:
Це фронтенд-фікс. Якщо великі відео з Google Drive все одно підвисають під час перемотування, наступний крок — оптимізувати /api/media/{id} у worker.js під HTTP Range/206 та кешування. Поточний Worker уже передає Range, тому це окремий backend-крок.
