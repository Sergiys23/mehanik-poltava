AI ДЛЯ ОСНОВНОГО САЙТУ МЕХАНІК ПОЛТАВА

Проблема: попередній клієнтський чат викликав /api/ai, але поточний worker.js не мав публічного маршруту.

1. Додайте ai-client.js та ai.css у public/.
2. Покладіть актуальний worker.js у корінь цієї папки.
3. Запустіть: python apply-ai-patch.py
4. Перевірте Cloudflare Bindings: AI = Workers AI, DB = D1.
5. Deploy.

AI використовує актуальні послуги/ціни/норми часу з D1.
