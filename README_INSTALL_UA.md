# Механік Полтава — оновлення заявок

У цьому архіві готові файли:
- worker.js — Telegram-видалення + архів заявок + API історії
- admin.html — вкладки «Заявки», «Історія», «Відгуки»
- schema.sql — нові таблиці D1

Що змінено:
1. Нова заявка зберігає ID повідомлення Telegram.
2. Кнопка «В архів» в адмінці переносить заявку в історію.
3. Повідомлення цієї заявки видаляється з Telegram.
4. Дані заявки залишаються в booking_history.
5. Старі заявки, створені ДО цього оновлення, можуть не мати прив'язаного Telegram message_id, тому їхнє старе повідомлення бот автоматично видалити не зможе.
6. Нові службові таблиці worker.js створює автоматично, тому окремий SQL-запуск для них не потрібен.

Важливе обмеження Telegram:
бот може видаляти повідомлення через Bot API лише в межах дозволеного Telegram терміну. Для звичайних повідомлень це до 48 годин. Якщо Telegram відмовить у видаленні старого повідомлення, сама заявка все одно потрапить в історію.

Заміна файлів:
1. У GitHub відкрий репозиторій.
2. Замінити worker.js.
3. Замінити admin.html.
4. schema.sql теж можна замінити для повної відповідності схеми.
5. Після деплою зробити тестову заявку.
6. Перевірити Telegram.
7. В адмінці натиснути «В архів».
8. Перевірити вкладку «Історія».

Не публікуй токен Telegram або пароль адміністратора у коді. Вони мають залишатися тільки в Cloudflare Secrets/Variables.

## Виконані роботи та Telegram

Після завершення таймера робота автоматично записується в окремий журнал `completed_works`. Запис не залежить від заявки: навіть якщо заявку пізніше архівувати, виконана робота залишається в статистиці та вкладці «Виконані роботи».

Telegram отримує окреме повідомлення з заголовком `🏁 ВИКОНАНА РОБОТА`. За замовчуванням воно йде в `TELEGRAM_CHAT_ID`. Для окремого Telegram-чату використовуйте `TELEGRAM_COMPLETED_CHAT_ID`. Якщо це форум/топіки, можна додатково вказати `TELEGRAM_COMPLETED_THREAD_ID`.

Worker також має погодинну cron-перевірку: якщо браузер адміністратора закритий, прострочений таймер все одно буде автоматично завершений і записаний у виконані роботи.
