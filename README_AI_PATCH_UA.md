# Механік Полтава — AI client patch

Цей ZIP містить готовий клієнтський модуль AI для поточного репозиторію.

Файли:
- `public/ai-client.js` — робочий інтерфейс AI та POST-запити до `/api/ai`.
- `public/ai.css` — стилі плаваючої кнопки та панелі AI.

У поточному репозиторії серверний `/api/ai` вже реалізований у `worker.js`, а `index.html` вже підключає `/ai.css` та `/ai-client.js`.

Покласти файли поверх відповідних файлів репозиторію.
